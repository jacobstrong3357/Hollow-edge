# Monster victory sheets

These 16 square sheets are the approved monster-victory artwork. Filenames use the game's monster names; `shapeshifter`, `doppelganger`, `night-hag`, and `hollowed` correspond to the runtime IDs `shifter`, `doppel`, `hag`, and `hollowed`.

Only approved final sheets belong in this directory. Drafts, setting plates, source concepts, and review contact sheets are intentionally excluded from the repository.
